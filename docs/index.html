A fleet of agents that works for you, so you stop being the bottleneck.

Most multi-agent frameworks ask how a team of agents writes code. Pororoca asks a different question: how does a busy person (a tech lead, a manager, a founder) get off the critical path of everything that lands on them?

Get startedMeet the agentsRoadmap
FiltersA gatekeeper decides what really needs you. Nothing else reaches you.
Does the workIt triages, investigates, builds the fix, opens the PR and follows it to production.
Speaks for you, within limitsRoutine replies go out on their own, signed 🤖. Sensitive changes go to a judge. Real decisions come back to you.
Chases until doneA card waiting on someone always has a chaser. "Handed off" is not "done".

Getting started

Linux and macOS (Windows: WSL). One binary, checked against the release SHA-256, installed in ~/.local/bin. Run the same line to update. Needs Claude Code logged in.
# install
curl -fsSL https://cavalcanticampos.github.io/pororoca/install.sh | sh
# fake inbox, no accounts: watch the fleet close cards
pororoca demo
# Claude Code, gh, git; each failure with its fix
pororoca doctor
# preset, your repos and (optionally) Slack; replies wait for your OK
mkdir my-fleet && cd my-fleet && pororoca init
# run the fleet
pororoca up
# what truly needs you
pororoca you
