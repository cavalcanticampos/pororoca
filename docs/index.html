A fleet of agents that works for you,
so you stop being the bottleneck.

Most multi-agent frameworks ask how a team of agents writes code. Pororoca asks a different question: how does a busy person (a tech lead, a manager, a founder) get off the critical path of everything that lands on them?

FiltersA gatekeeper decides what really needs you. Nothing else reaches you.
Does the workIt triages, investigates, builds the fix, opens the PR and follows it to production.
Speaks for you, within limitsRoutine replies go out on their own, signed 🤖. Sensitive changes go to a judge. Real decisions come back to you.
Chases until doneA card waiting on someone always has a chaser. "Handed off" is not "done".

One week of the reference fleet

Pororoca comes from a private fleet run for one tech lead. These are its numbers for one week:

7%
of 1,377 incoming items needed the human
98.5%

608

Getting started

Nothing to install yet. Milestone M1 (core, CLI, local inbox and GitHub) is in progress. Follow along in the PRD.
# the plan for M1
pororoca init      # pick solo mode, connect GitHub, write a 6-agent maloca.yaml
pororoca up        # start the fleet in shadow mode
pororoca you       # what truly needs you
pororoca metrics   # share of work resolved without you
