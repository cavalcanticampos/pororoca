Integrations

Everything outside the core is a port with adapters. This matrix shows each adapter, how far it has got and whether it can speak as you.

Availability: Built in ships in a release · Planned · Mx is on the roadmap at that milestone · Requested was asked for and isn't built.
Picks up work: push, poll, or "Pororoca wakes it".
Checked: the release and date it was last run end to end. A label only changes after a run on a published release.
